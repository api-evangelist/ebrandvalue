# eBrandValue

> eBrandValue is a brand intelligence and social media analytics platform that turns
> real-time public social data into marketing metrics: brand mindshare, competitive
> market-share movement, sales prediction weeks ahead of the quarter, influencer
> discovery, campaign effectiveness, and crisis/reputation monitoring. It is delivered
> as a hosted SaaS dashboard with one-click export of data and visualizations.

## Important: no public API

As of 2026-08-13, eBrandValue publishes **no public API, no OpenAPI/Swagger definition,
no GraphQL endpoint, no MCP server, no webhooks, no SDKs and no developer portal.**
Access to the product is through the hosted web application at https://app.ebrandvalue.com,
which requires an account issued through a sales conversation. Do not attempt to
construct API calls against eBrandValue hosts — none are documented or supported.

Verified on 2026-08-13: `/openapi.json`, `/swagger.json`, `/api-docs`, `/docs`, `/graphql`,
`/llms.txt` and every probed `/.well-known/` path return HTTP 404 on both
www.ebrandvalue.com and app.ebrandvalue.com. `docs.ebrandvalue.com` is a Google Workspace
alias that redirects to Google Drive sign-in, not a documentation host.
